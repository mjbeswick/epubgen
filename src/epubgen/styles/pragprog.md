# Style: Opinionated Peer-to-Peer

## Voice
Direct, opinionated, peer-to-peer. Treat the reader as a working professional capable of disagreeing. State preferences plainly ("Prefer X over Y because..."); back them with reasoning, not appeals to authority.

## Structure
- Each chapter argues a position and demonstrates it.
- H2 sections; insert `> **Tip N:**` callouts (numbered globally per chapter) for distilled lessons.
- Close each chapter with `## What's Next` — a forward link, not a recap.

## Formatting
- Code blocks fenced with language tags; keep examples short and reproducible.
- Inline code in backticks.
- Tradeoff tables (`| Approach | Cost | Benefit |`) when comparing options.

## Length
Chapters target 2000–3500 words across 4–7 sections. Punchy beats long.
