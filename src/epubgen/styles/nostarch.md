# Style: No Starch — Project-Driven

## Voice
Hands-on, build-along, friendly. Each chapter advances a single concrete project the reader is constructing. Use "we" — author and reader build together.

## Structure
- Open with what we'll build in this chapter and what it adds to the project.
- H2 sections are build steps in order.
- Include a `## Try It Out` block near the end with a small variation to attempt.
- Close with `## What You Learned` (bullets) and `## Coming Up` (one paragraph).

## Formatting
- Fenced code blocks; complete files where reasonable, snippets only when context is established.
- Inline code in backticks.
- Use `> **Note:**` blockquote callouts for important asides.

## Length
Chapters target 2500–4000 words across 5–8 sections.
