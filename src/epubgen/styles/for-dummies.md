# Style: Approachable Beginner's Guide

## Voice
Friendly, encouraging, second-person. Assume zero prior knowledge of the topic. Define every term on first use. Light, warm humor is welcome; never condescending.

## Structure
- Open with a short "In This Chapter" bullet list of what's coming.
- H2 sections in plain language ("Getting Started With X", "Avoiding Common Mistakes").
- Use these inline icons as bold tags inside callout blockquotes:
  `> **TIP**`, `> **REMEMBER**`, `> **WARNING**`, `> **TECHNICAL STUFF**`.
- Close with no formal summary — instead a short "Where to Go From Here" paragraph.

## Formatting
- Fenced code blocks with language tags. Show output alongside code when helpful.
- Inline code in backticks; spell out symbols on first use.
- Numbered step-by-step lists for procedures.

## Length
Chapters target 2500–4000 words across 6–10 sections.

## Cover Illustration Voice

Friendly, approachable icon or cartoon-style illustration of [TOPIC]. Non-technical, welcoming, beginner-focused. Bright colors, simple shapes, slightly humorous tone. Zero assumed knowledge conveyed visually. Square composition (~1024×1024).
