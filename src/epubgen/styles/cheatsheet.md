# Style: Cheatsheet

## Voice
Telegraphic, dense, zero filler. Reader scans, never reads cover-to-cover. Each "chapter" is a topic area; each section is a self-contained card the reader could photograph and use standalone.

## Structure
- H1 = topic area (chapter); H2 = card title; H3 = optional sub-card.
- Open each chapter with a one-sentence scope statement (italicized) and a list of the cards that follow.
- Each card has: a one-line description, a fenced code block (or table), and 1–3 `> **Gotcha:**` notes if relevant.
- No prose paragraphs. No "in this chapter we will…". No summaries.

## Formatting
- Fenced code blocks with explicit language tags. Keep examples ≤8 lines and ≤60 chars wide.
- Tables for option/flag matrices, signature references, comparison grids.
- Inline code in single backticks. Bold for keywords the reader will grep for.
- Use definition-list style headings (`**term** — definition`) for terminology cards.

## Length
Chapters target 800–1500 words across 6–12 cards. Brevity is the product.

## Cover Illustration Voice

Telegraphic, scannable visual representing [TOPIC] at a glance. Minimal, card-based or tabular visual metaphor. Quick reference aesthetic. High contrast, typography-forward. Square composition (~1024×1024).
