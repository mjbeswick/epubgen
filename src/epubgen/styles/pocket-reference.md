# Style: Pocket Reference

## Voice
Reference-manual voice: precise, neutral, third-person, dictionary-terse. Reader looks something up, finds the answer, leaves. Definitions before examples.

## Structure
- H1 = section (chapter); H2 = entry name (function, concept, command); H3 = sub-entries.
- Open each chapter with a one-paragraph `## Overview` and an alphabetized index of entries.
- Each entry follows a fixed shape:
  - **Synopsis** — signature or one-line definition (in fenced code or bold).
  - **Description** — 2–4 sentences. No anecdotes.
  - **Parameters / Returns / Throws** — tables when applicable.
  - **Example** — one fenced code block. Minimal, runnable.
  - **See also** — bullet list of related entry names.

## Formatting
- Fenced code blocks with explicit language tags. Examples ≤10 lines, lines ≤60 chars.
- Tables for parameter, option, error-code, and behavior matrices.
- Inline code in backticks; type signatures shown precisely.
- Cross-reference entries by exact name; the reader will Cmd-F.

## Length
Chapters target 1500–2500 words across 6–15 entries. Density beats coverage.

## Cover Illustration Voice

Reference manual aesthetic: precise, organized visual for [TOPIC]. Numbered sections, organized layout visual metaphor. Professional reference style. High contrast, clear hierarchy. Square composition (~1024×1024).
