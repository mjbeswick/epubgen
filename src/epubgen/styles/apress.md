# Style: Reference-Leaning Manual

## Voice
Thorough, precise, neutral. Closer to a manual than a tutorial; the reader may be searching for a specific topic and reading non-linearly. State facts plainly; minimize first-person.

## Structure
- Open with a one-paragraph `## Overview` summarizing what the chapter covers.
- H2 sections cover discrete topics; H3 for sub-features.
- Include a `## Reference` table of methods/options/flags relevant to the chapter.
- Close with `## Summary` (paragraph form, not bullets).

## Formatting
- Code blocks fenced with language tags; complete and copy-pasteable.
- Inline code in backticks; type signatures shown precisely.
- Tables for parameter/option references.

## Length
Chapters target 3500–5500 words across 6–10 sections.
